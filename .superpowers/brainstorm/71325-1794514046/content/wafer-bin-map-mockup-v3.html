What the badges mean

  1. ① Title — wafer ID + sites, merged across A..W (Title lookalike).
  2. ② Info row — Yield / Total / Pass / Failed / Unknown / Superseded / WAFER_ID / FABWF_ID… (one row per selected site under the title when several sites are checked).
  3. ⑦ SW bin table, columns A:D — your ruling: a real Excel Table (add_table) with filter arrows and the blue Distribution data bar; fed by this map's counts (per-wafer, not the file-level Bin sheet); the SBIN cells carry the same palette fills → doubles as the legend.
  4. spacer column E — blank, separates table from map.
  5. ④ Y-axis header, column F — die Y coordinates per invertY (Y ascends upward on the GUI map, so max Y on top row).
  6. ③ X-axis header row — die X coordinates per invertX (default: ascending left→right), above the die grid only.
  7. ⑤ Die cells, G..W — square 24×24 px; cell value = sbin number (real number: filterable, COUNTIF-able); CF rule per bin cell == sbin → palette fill; font black/white by fill luminance.
  8. ⑥ Round silhouette — coordinates outside the wafer circle: empty cells, no fill, no border.
  9. ⑧ One block per wafer — stacked wafer (fail-count colormap) keeps the existing PNG image, out of scope. A wafer with zero dies shows title + info rows only (your ruling).
